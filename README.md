# 🏥 Hospital Emergency Room Analysis Dashboard

An interactive Power BI dashboard that analyzes hospital emergency room operations, turning raw patient-visit data into actionable insights for operational and clinical decision-making.

## 📌 Project Overview

Emergency rooms generate large volumes of operational data every day — patient arrivals, wait times, admissions, referrals — but this data is only useful if it can be turned into insight quickly. This project builds a Power BI dashboard that helps hospital management understand ER performance at a glance: how many patients are being seen, how long they wait, how satisfied they are, and when the ER is under the most pressure.

## 🎯 Objective

To design an interactive, decision-support dashboard that helps hospital administrators:
- Monitor patient volume and demand patterns
- Track wait times and satisfaction against targets
- Understand admission vs. non-admission trends
- Identify peak days/hours to support staffing decisions
- Analyze referral patterns across departments
- Understand patient demographics (age, gender, race)

## 🗂️ Dataset

The dataset contains **9,216 emergency room patient records**, including fields such as visit date/time, wait time, patient satisfaction score, admission status, referral department, and patient demographics.

## 📊 Key Metrics & Insights

- **Total Patients Analyzed:** 9,216
- **Average Wait Time:** 35.3 minutes
- **Average Satisfaction Score:** 4.99 / 10
- **Most Common Referral Department:** General Practice
- **Highest Patient Volume Day:** Monday
- **Peak Activity:** Late mornings and evening hours

## 📈 Dashboard Features

- Patient Volume Trends over time
- Average Wait Time analysis
- Patient Satisfaction Score tracking
- Admission vs. Non-Admission breakdown
- Department Referral Pattern analysis
- Demographic Analysis (Age, Gender, Race)
- % of Patients Seen Within Target Time
- Peak Day & Hour heatmap/analysis
